# MITRE ATT&CK® content in these captures

Some replies in this directory were captured from a development OpenCTI
instance into which the MITRE ATT&CK dataset had been ingested (by the
OpenCTI MITRE connector), and they hold ATT&CK text as the instance returned
it — names, aliases, descriptions and relationship descriptions. Notably:

- `entity-apt28.json`
- `related-apt28-uses-attack-pattern.json`

and, to a lesser degree, the search and recent-item captures that name
ATT&CK objects.

They are kept as evidence for the measurements in
`docs/ja/opencti-lookup-phase0.ja.md`. This project is not affiliated with or
endorsed by The MITRE Corporation.
